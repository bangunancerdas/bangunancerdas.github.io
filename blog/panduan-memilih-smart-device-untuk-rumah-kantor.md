# Panduan Memilih Smart Device untuk Rumah/Kantor

Mulai dari kebutuhan utama: pencahayaan, kontrol AC, keamanan, atau monitoring energi. Pilih perangkat yang kompatibel dengan ekosistem terbuka agar mudah diintegrasikan.

Pastikan juga ada opsi local control supaya sistem tetap berjalan saat internet tidak stabil.
